## 2. 产品简介

EmbodTeachMS 具身课堂用于组织具身智能课程的资料、备课、发布、学习活动和学情分析。系统包含教师与学习者两个固定角色：

- 教师负责教学班、知识库、备课、练习、作业和学情查看。
- 学习者负责加入教学班、阅读课程、完成练习与作业并查看个人概览。
- 两个角色都可查看项目内置的具身智能三维教学演示。

## 3. 使用前准备

### 3.1 推荐环境

- Windows 10/11 64 位。
- Node.js 24、npm 11。
- Python 3.13。
- uv 0.8 或更高。
- 最新版 Chrome 或其他现代桌面浏览器。

### 3.2 首次安装

在项目根目录打开 PowerShell：

```powershell
cd backend
uv sync --dev

cd ..\frontend
npm install
cd ..
```

项目默认使用 SQLite，无需单独安装数据库服务。

### 3.3 一键启动

在项目根目录执行：

```powershell
.\start.ps1
```

默认访问地址：

| 用途 | 地址 |
| --- | --- |
| 产品 Demo | `http://127.0.0.1:45173` |
| 后端接口 | `http://127.0.0.1:38117` |
| Swagger 文档 | `http://127.0.0.1:38117/docs` |
| 运行日志 | 项目根目录 `.runtime/` |

如端口被占用：

```powershell
.\start.ps1 -BackendPort 8002 -FrontendPort 5174
```

脚本会自动生成本地 JWT 密钥，并将实际前端来源和后端地址传给两个服务。

### 3.4 停止服务

在运行 `start.ps1` 的终端按 `Ctrl+C`。脚本会终止本轮启动的前后端进程树。提交或交接前请确认没有遗留 Node.js 或 Python/Uvicorn 进程。

## 5. 推荐演示路线

评审建议按以下顺序操作：

1. 使用教师账号登录，进入“我的课程”。
2. 进入“知识库管理”，创建知识库并上传 Markdown 课程资料。
3. 查看分段、应用规则重建索引，并执行一次召回测试。
4. 将资料导入“具身智能课程班”。
5. 进入该班“课件备课”，选择资料、划重点、创建并确认题目。
6. 发布课程内容，并按需发布作业。
7. 退出教师账号，使用学习者账号进入教学班。
8. 阅读当前课程、完成课堂练习并提交作业。
9. 打开“学习概览”查看个人结果。
10. 切回教师账号，在班级概览、学习者详情、课堂练习管理和作业管理中查看结果。
11. 打开“三维演示”，逐步查看机器人接收指令、感知环境、规划和执行过程。

完成后可以看到从课程资料到学习证据的完整数据闭环。

## 6. 教师使用指南

### 6.1 注册与登录

1. 打开产品 Demo 地址。
2. 在注册页选择“教师”。
3. 填写用户名、密码和显示名称。
4. 注册成功后登录。
5. 登录落点为“我的课程”。

Token 无效或过期时，系统会清理会话并返回登录页，请重新登录。

### 6.2 创建教学班

1. 在“我的课程”选择创建教学班。
2. 填写教学班名称和必要课程信息。
3. 进入教学班工作区。
4. 根据使用场景设置加入方式：

| 加入方式 | 学习者行为 | 教师操作 |
| --- | --- | --- |
| 自由加入 | 学习者直接加入 | 无需审批 |
| 申请加入 | 学习者提交申请 | 教师在申请管理中批准或拒绝 |
| 关闭加入 | 无授权码时不能加入或申请 | 可单独创建授权码 |

授权码只对应一个教学班，可启用、停用并设置失效时间。

### 6.3 创建知识库

1. 从“我的课程”或班级快捷入口打开“知识库管理”。
2. 创建教师级知识库，填写名称和描述。
3. 上传 `.md` 或 `.markdown` 课程资料。
4. 等待文档进入可处理状态。

当前推荐使用 Markdown。PDF/DOCX 需要额外部署 MinerU，未配置时不要作为核心演示输入。

### 6.4 管理知识库文档

教师可以：

- 修改文档标题和 Markdown 内容。
- 替换原始文件。
- 删除文档。
- 对失败文档执行重试。

编辑或替换会使旧分段和索引失效，需要重新预览并构建。系统显示失败时应先查看具体原因，不要把空召回结果当成构建成功。

### 6.5 预览分段与测试召回

1. 选择知识库和目标文档。
2. 点击“查看分段”或“分段预览”。
3. 选择简单或高级分段规则。
4. 检查标题路径、片段长度、来源位置和正文。
5. 确认后点击“应用规则并重建”。
6. 在召回测试中输入一个课程问题。
7. 选择关键词、向量或混合检索并查看 Top-K 结果。

若 Embedding 未配置：

- 关键词检索仍可使用。
- 向量或混合检索会显示不可用或降级原因。

### 6.6 将资料导入教学班

1. 在教师级知识库勾选一个或多个文档。
2. 选择目标教学班。
3. 选择冲突策略：

| 策略 | 行为 |
| --- | --- |
| 跳过 | 目标班已有冲突文档时不导入 |
| 替换 | 使用来源文档替换目标冲突文档 |
| 另存为副本 | 保留现有文档并创建新副本 |

4. 执行导入。
5. 返回目标教学班备课页。

教学班中的文档是独立副本。来源知识库后续修改不会自动覆盖班级内容。

### 6.7 课件备课

备课流程分为四步：

1. **选择资料**：从教学班知识库选择已完成处理的文档。
2. **划重点**：在段落文本上选择内容并保存重点；点击已有高亮可删除。
3. **维护题目**：基于重点生成候选题，或手工创建单选/多选题。
4. **确认并发布**：逐题编辑、确认或删除。

发布条件：

- 至少有一道已确认题目。
- 不存在未处理的候选题。
- 备课资料已完成处理。

### 6.8 发布课程和作业

课程/课堂练习发布：

1. 检查课件正文和题目。
2. 确认发布目标教学班。
3. 点击发布。

作业发布：

1. 填写作业标题和说明。
2. 设置晚于当前时间的截止时间。
3. 检查题目均已确认。
4. 发布到当前教学班。

发布后形成内容快照，后续修改知识库不会改变已发布历史内容。

### 6.9 查看教学结果

教师可使用以下页面：

- **班级概览**：查看课程进度、完成情况和掌握度分布。
- **学习者详情**：查看指定成员的练习、作业和结构化依据。
- **课堂练习管理**：查看已发布练习和答题情况。
- **作业管理**：查看提交、迟交和客观题结果。
- **申请管理**：处理待加入申请。
- **授权码管理**：创建、停用或查看有效期。

教师不能查看学习者原始伴学聊天，也不能访问其他教师的教学班数据。

## 7. 学习者使用指南

### 7.1 注册与登录

1. 在注册页选择“学习者”。
2. 填写账号信息并完成注册。
3. 登录后进入“我的课程”。

### 7.2 加入教学班

学习者可通过以下方式加入：

- 在可发现列表中直接加入自由开放的教学班。
- 对申请制教学班提交申请，等待教师批准。
- 输入教师提供的有效授权码直接加入。

“申请中”不代表已经加入，在批准前不能读取本班发布课程。

### 7.3 学习课程

1. 在“我的课程”打开已加入教学班。
2. 进入“当前课程”。
3. 选择已发布课件并阅读正文。
4. 完成后主动点击完成操作。

重复点击完成不会重复累计记录。

### 7.4 完成课堂练习

1. 在课程内容中打开课堂练习。
2. 阅读题目并选择答案。
3. 提交后查看确定性对错结果和解释。

单选和多选按后端保存的正确答案集合判定，AI 不参与修改判分结论。

### 7.5 完成基准练习

1. 提交首次答案。
2. 若回答错误，可查看一次提示。
3. 完成再次作答。
4. 查看最终反馈和相关掌握依据。

同一学习者对同一运行不会因重复请求产生多份冲突证据。

### 7.6 完成作业

1. 打开待完成作业。
2. 保存答题草稿。
3. 检查后提交。
4. 查看客观题结果。

超过截止时间仍可提交时，系统会标记为迟交。已提交后的可修改范围以页面状态为准。

### 7.7 查看学习概览

“学习概览”展示：

- 已发布内容和完成情况。
- 练习与作业结果。
- 知识点状态和掌握依据。
- 下一步学习提示（如当前数据足够）。

学习者只能查看自己的个人数据。

## 8. 三维具身智能演示

1. 打开“三维演示”页面。
2. 选择一个内置教学任务。
3. 使用“上一步”“下一步”观察任务阶段。
4. 重点观察指令输入、环境感知、任务理解、路径规划和动作执行之间的关系。

该演示使用 Three.js 和项目内置资源，在未安装 Webots 时也可运行。它用于解释具身智能工作流程，不等同于真实机器人控制或 Webots 评价结果。

## 9. 可选 AI 功能配置

复制 `backend/.env.example` 为 `backend/.env`，设置：

```dotenv
CANVAS_AGENT_LLM_API_KEY=replace-with-your-api-key
CANVAS_AGENT_LLM_BASE_URL=https://api.deepseek.com/v1
CANVAS_AGENT_LLM_MODEL=deepseek-v4-flash
CANVAS_AGENT_LLM_TIMEOUT_SECONDS=20
```

注意：

- API Key 不得提交到 Git。
- 模型名必须以服务商当前实际提供的模型为准。
- 未配置密钥时，AI 入口会明确降级，不会伪造回答或题目。
- AI 候选题必须由教师确认才能发布。

## 10. 可选 MinerU 配置

仅使用 Markdown 时不需要 MinerU。需要解析 PDF/DOCX 时，在 `backend/.env` 中设置：

```dotenv
MINERU_BASE_URL=http://mineru.internal:8080
PARSING_TIMEOUT=300
MAX_PAGES=100
MAX_PARAGRAPHS=1000
MAX_OUTPUT_SIZE=10485760
```

当前项目适配器要求符合项目约定的解析 HTTP 契约。正式使用前应核对实际 MinerU 服务版本、安全限制和返回结构。

## 11. 分别启动方式

若不使用一键脚本，可分别启动。

后端：

```powershell
cd backend
$env:COURSE_AGENT_JWT_SECRET='replace-with-at-least-32-random-characters'
uv run uvicorn app.run:app --host 127.0.0.1 --port 38117
```

前端（另开终端）：

```powershell
cd frontend
$env:VITE_API_BASE_URL='http://127.0.0.1:38117'
npm run dev -- --host 127.0.0.1 --port 45173
```

## 12. 运行验证

后端测试：

```powershell
cd backend
uv run pytest
```

前端类型检查与构建：

```powershell
cd frontend
npm.cmd run typecheck
npm.cmd run build
```

双角色 E2E：

```powershell

```

如果验证失败，先查看依赖安装和 TypeScript 编译错误，再检查端口、环境变量和服务状态。

## 13. 常见问题

### 13.1 页面无法打开

- 确认 `start.ps1` 终端没有报错。
- 确认访问的是脚本输出的实际端口。
- 若端口占用，使用 `-BackendPort` 和 `-FrontendPort` 指定新端口。

### 13.2 登录后立即回到登录页

- Token 可能无效或数据库已更换。
- 重新登录；仍失败时检查后端日志和 JWT 密钥长度。

### 13.3 上传后不能备课

- 检查文档是否完成处理和索引构建。
- 教师级知识库文档需先导入目标教学班。
- 备课页只显示当前班级知识库中可用的文档。

### 13.4 不能发布

- 确认至少一道题已确认。
- 处理或删除所有候选题。
- 确认资料处理完成。
- 发布作业时检查标题和截止时间。

### 13.5 AI 功能不可用

- 检查 `CANVAS_AGENT_LLM_API_KEY`、Base URL 和模型名。
- 检查后端能否访问模型服务。
- 未配置时属于预期降级，课程、练习和作业仍可使用。

### 13.6 PDF/DOCX 无法解析

- 默认核心流程仅依赖 Markdown。
- 检查 MinerU 服务地址、超时和返回契约。
- 解析失败时查看页面错误原因和后端日志。

### 13.7 向量检索不可用

- 检查 Embedding 配置和服务可达性。
- 可以先使用关键词检索完成 Demo。
- 不要将零结果视为向量索引成功。

## 14. 数据与安全注意事项

- `.env`、API Key、JWT 密钥不得提交。
- 本地数据库和上传资料可能包含账号或课程数据，外发前需检查。
- 不要在真实生产环境使用演示账号密码。
- 日志中不应写入完整课件、原始聊天或凭证。
- 教师只应使用自己拥有的教学班和已获授权的课程资料。

## 15. 产品能力边界

- 本项目是 PoC，不是生产级教学平台。
- 未配置外部服务时，AI、PDF/DOCX 和真实 Webots 能力会受限。
- Three.js 三维演示用于教学理解，不代表真实仿真已经完成。
- 个性化练习真实生成能力仍需后续优化。
- 当前不支持管理员、多课程、正式成绩、主观题和大规模并发。
